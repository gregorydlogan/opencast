# What is a Capture Agent

A Capture Agent (also widely known as a CA) is a system which captures one or more inputs and sends (ingests) that
captured data to your Opencast core for further processing.  This is a deliberately vague definition because Opencast
is an open system by default: Anyone can build a capture agent, and as long as it understands how to interact with
Opencast properly it is, by definition, a CA.
